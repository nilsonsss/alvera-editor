# Video Editing System

Turns raw talking-head clips into a finished vertical video (1080x1920): tight cuts, framing, captions, animated graphics, sound effects and loudness. You drive it by talking to Claude Code. No video editor app is needed.

## Start
1. Open this folder in [Claude Code](https://claude.com/claude-code).
2. Say "Set it up". Claude installs everything (about 15 minutes the first time, mostly downloads; about 10 GB). Approve its commands if asked.
3. Say "Set up my brand": your colours, typeface file and language.
4. Say "Edit these clips into a reel: <paths>". Finished files appear in `projects/<job>/outputs/`, with a report next to them.

Made for Apple Silicon Macs. Ask for any graphic you like: Claude can use the ready-made ones or build new ones.
